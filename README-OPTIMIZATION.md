## ⚠️ 注意事项

### 1. 服务器负载

增加并发线程会增加服务器负载，建议：
- 监控 CPU 和内存使用
- 确保 JVM 堆内存充足（2GB+）
- 必要时调整线程数

### 2. 爬取礼仪

- 遵守目标网站的 robots.txt
- 考虑添加请求延迟
- 避免对目标网站造成过大压力

### 3. 网络带宽

更多页面意味着更多带宽消耗：
- 确保网络稳定
- 考虑使用代理池
- 监控流量使用
