如何使用 Sitemap Studio

  1. 输入完整网址（含 http/https），内网地址会被拒绝。
  2. 需要图片或视频收录时，在设置里打开对应开关。
  3. 抓取时在实时看板查看已发现、已加入和用时。
  4. 完成后下载 XML，结果按任务保存，可重复下载。

限制

  • 最多 500 个 URL，超出后停止发现新页面。
  • 只在输入网址的域名范围内抓取，不做跨域跟随。
  • 私网 IP、localhost 和内网域名会被安全策略拒绝。

给搜索引擎的路线图

Sitemap Studio 的流程参考 xml-sitemaps.com：输入网址、展开设置、实时看板、下载 XML，但用一套更现代、更克制的界面语言呈现。

抓取通道遵循 robots.txt、同域范围和逐跳重定向校验：所有页面请求都经过统一的安全校验，不会访问内网地址。

流程

  • 输入完整网址
  • 按需打开媒体设置
  • 实时看抓取进度
  • 下载并提交 sitemap.xml
